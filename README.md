# FPGA implementation of NEZ

This repository is for an FPGA-oriented implementation of
[NEZ](https://github.com/nez-peg/nez), a PEG-based parsing system.

## Status

The project is in its initial setup stage. The repository currently documents the
goal and scope of the work and will grow to include HDL sources, testbenches, and
supporting documentation.

## Goals

- implement the core NEZ execution model in FPGA-friendly hardware blocks
- evaluate parser throughput, latency, and resource usage
- provide reproducible examples, tests, and design notes for the implementation
